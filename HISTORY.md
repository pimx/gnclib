- lib_integrate.h, IntegrateRK4 -- ориентация 4-го порядка. До 1.7.0
  наклонами вектора поворота на стадиях и в итоге служили сами угловые
  скорости w_i: это схема Ли-Эйлера без поправки dexp^-1, 2-й порядок по
  ориентации, когда направление угловой скорости меняется на шаге (член
  некоммутативности -- конинг). Теперь RKMK4 (Munthe-Kaas): наклоны
  k_i = w_i + th_i x w_i / 2 + th_i x (th_i x w_i) / 12 (уравнение Бортца
  для угловой скорости в связанных осях), th_2 = dt/2 w_1,
  th_3 = dt/2 k_2, th_4 = dt k_3, итог -- exp(dt (w_1 + 2 k_2 + 2 k_3 +
  k_4) / 6). Поступательное движение, угловая скорость и вспомогательные
  состояния -- как прежде.
  НЕСОВМЕСТИМОЕ по числам: при вращении с меняющимся направлением угловой
  скорости числа другие (точнее); вращение вокруг одной оси -- побитно
  прежние (члены с векторным произведением дают точный ноль; ЗАМЕРЕНО).
  Сверки потребителей с пространственным вращением надо переснять.
