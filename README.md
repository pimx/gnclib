# gnclib

Статическая библиотека GNC: атмосфера, аэродинамика (полосовая модель
цилиндра, экранирование ретро-струёй, экранный эффект), геодезия
(эллипсоиды ПЗ-90.11 и WGS-84; ECEF/ENU, строгая сила тяжести J2 +
центробежная), фреймы и
кватернионы, ветер, CLI, утилиты. C++17, без STL/исключений/RTTI/куч.

Сборка: `make` (g++, build/libgnc.a) или `build.bat` (VS2026,
build\gnc.lib). Заголовки -- include/, версия -- include/gnclib_version.h;
тег репозитория обязан совпадать с GNCLIB_VERSION.

Потребители подключают: -I<gnclib>/include и линкуют build/libgnc.a
(gnc.lib). Сборка потребителей против main запрещена -- только тег.

## 1.1.0 — интегрирование с силами на стадиях, вращающаяся Земля

- `lib_integrate.h` — `IntegrateRK4(s, aux, dt, fn, ctx)`: RK4 движения
  твёрдого тела с пересчётом сил на каждой стадии и вспомогательными
  состояниями (`AuxState`, до 32). `Integrate` (силы постоянны на шаге)
  остаётся лёгким вариантом.
- `lib_earth.h` — `EarthGravityLoc`, `EarthRateLoc`, `CoriolisAccLoc`,
  `SpecificForceLoc`: вращающаяся Земля в системе площадки (= ECEF).
- Проверка: `make test`.
- `lib_aero_strip.h` — полосовая модель с поправками Cd по числу Маха
  (снят в 1.6.0: данные изделия).
- `lib_eskf.h` (+ `src/lib_eskf_*.cpp`) — общий навигационный ESKF
  `gnc::Eskf`; `lib_nav_types.h` — данные измерений; `lib_imu.h` —
  `ImuIdeal`, идеальные показания ИНС на вращающейся Земле с рычагом.
  Подключаются явно (не через `lib.h`).

## 1.4.0 — быстрый расчёт точки модели

- `lib_geodesy.h` — `EcpToAlt(p, el)` и `GEO::AltOf(l)`: только
  геодезическая высота, итерация `EcpToGeo` без тригонометрии (отличие
  не более 7.5e-9 м, примерно в 7 раз дешевле).
- `lib_atmosphere.h` — `AtmState`, `EnvAtmosphere::State(h)`: температура,
  давление и плотность за один проход, те же числа побитно; строка
  верхней таблицы находится сразу.
- `lib_aerodynamics.h` — цикл `CylinderStrip` без нулевых слагаемых (те же
  суммы побитно), `CylinderStripPair` — полосы вращающегося и неподвижного
  тела за один проход.
- Проверка: `make test` (`tests/test_point.cpp`).

## 1.5.0 — широта без тригонометрии

- `lib_geodesy.h` — `CfGeoSc`, `EcpToGeoSc(p, el)`: широта синусом и
  косинусом и высота (итерация `EcpToGeo` без тригонометрии; `EcpToAlt`
  теперь через неё, числа те же); `GeoRadius(sinLat, cosLat, alt, el)` —
  расстояние от центра до точки на широте и высоте (длина `GeoToEcp`,
  от долготы не зависит) без тригонометрии.

## 1.6.0 — общие функции; данные конкретных изделий вынесены

В библиотеке нет упоминаний проектов-потребителей и характеристик
конкретных изделий (решение владельца 17.10.2026).

Новое (подключается явно, не через `lib.h`: короткие имена `Limit`,
`Deg`, `Eso2`, `Notch` не должны встречаться с именами потребителей
`lib.h`):

- `lib_util.h` — `Limit(v, limit)` (по модулю), `Clamp(v, lo, hi)`,
  `Deg(d)`, `ToDeg(r)` (выражение `d * (PI / 180)`).
- `lib_table.h` — `TableLocate` (строка и доля в возрастающей таблице,
  края удерживаются), `TableBilinear` (билинейная интерполяция по таблице,
  хранимой построчно).
- `lib_eso.h` — `Eso2` (канал 1-го порядка, точная дискретизация по
  полюсу) и `Eso3` (канал 2-го порядка, тройной полюс, явный шаг).
- `lib_notch.h` — `Notch`, `NotchInit`, `NotchStep`: режекторный фильтр с
  подвижным центром.
- `lib_gust.h` — `GustTones`, `GustTonesAt`: порывы как чистая функция
  времени (сумма синусоид); все параметры задаёт потребитель.
- `lib_wind_profile.h` (+ `src/lib_wind_profile.cpp`) — `WindProfile`,
  `ReadWindProfile`, `WindProfileAt`: профиль ветра «высота, скорость,
  азимут» из файла.
- `lib_orbit.h` — `InertialState`, `InertialOf` (инерциальная скорость,
  наклон траектории, наклонение по движению над вращающейся Землёй),
  `CircularSpeed`, `LaunchAzimuthStart` (начальный азимут пуска на
  наклонение), `GeoAtLevel` (точка системы площадки на заданной высоте над
  эллипсоидом).

НЕСОВМЕСТИМЫЕ изменения (данные изделий -- у потребителей):

- `lib_aero_strip.h` снят (таблицы поправок Cd по Маху и полосовая модель
  на них -- данные изделия).
- `EnvAeroforces`: сняты `CxMachLanding`, `CxMachAscent`,
  `MachFactorAxial`, `DragLandingMagnitude`, `DragLanding`,
  `DragDecelLanding`, `FinForceMax`. `CylinderStrip` -- без аргумента
  `mach`: `cdAxial` передаётся таким, каким действует (поправку по Маху,
  если она нужна, считает потребитель).
- `Eskf::Config`: шумы датчиков без умолчаний (NaN); `Eskf::setup`
  возвращает `false` и называет незаданное поле в stderr.
- Проверка: `make test` (`tests/test_common.cpp`).

## 1.7.0 — плескание топлива

Новое (только добавления; подключается явно, не через `lib.h`):

- `lib_slosh_types.h`, `lib_slosh.h` (+ `src/lib_slosh_*.cpp`) —
  пружинно-массовый аналог плескания в связанных осях. Параметры по
  степени заполнения и осевой перегрузке: аналитика цилиндра с плоским
  днищем (`SloshCylinderRow`) или таблица потребителя
  (`SloshTable`, `SloshTableLoadCsv` / `SloshTableSaveCsv`);
  демпфирование гладкой стенки и кольцевых перегородок (Майлс, по
  амплитуде). `gnc::SloshModel` работает внутри `IntegrateRK4`: состояния
  плескания — `AuxState` (4 на тон), интегрируется жёсткая часть — сухая
  конструкция + неподвижные массы жидкости (`AssembleRigid`); `Eval`
  возвращает силу, полный момент и действующий INR для `DynDeriv`.
- Проверка: `make test` (Windows: `test.bat`), `tests/test_slosh.cpp`;
  CSV проверки частот и параметров — `build/slosh_out`.

## 1.11.0 — вращение Земли во вращательной динамике, стартовые системы координат

- `lib_integrate.h` — `IntegrateRK4`: новое поле `DynDeriv::earthRate`
  (угловая скорость Земли в местных осях, `EarthRateOmg`). Если его задать,
  угловая скорость в состоянии остаётся относительной (к системе площадки), а
  её производная учитывает гироскопический член абсолютной скорости и поворот
  угловой скорости Земли в связанных осях (`EpsOfRel`, `lib_dynamics.h`):
  тело без моментов сохраняет ориентацию в инерциальном пространстве.
  Поле не задано (0) — числа 1.10.0 побитно. `Integrate` (лёгкий вариант) —
  как прежде, система площадки квазиинерциальна.
- `lib_earth.h` — `EarthRateOmg(geo)`: угловая скорость Земли в местных осях
  как `CfLocalOmega`.
- `lib_launch.h` (подключается явно) — стартовые системы по справочному
  документу «Системы координат»: `LaunchAxesOf` (оси ССК / НССК в ECEF,
  матрица (7) ГИСК -> НССК), `InertialToEcef` / `EcefToInertial` (ГИСК <->
  ГОСК, (5)), `InertialVelRel` (скорость относительно Земли, (6)),
  `NsskToLoc` (направление, неподвижное в НССК, в местных осях на момент t),
  `SskToLoc` / `LocToSsk`, `LaunchBodyAxes` (связанные оси по тангажу,
  рысканию, крену, матрица (8)); тип `CfLaunchVector`.
- Проверка: `make test` (Windows: `test.bat`) — `tests/test_integrate.cpp`
  (g), `tests/test_launch.cpp`.
